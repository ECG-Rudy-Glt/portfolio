Beyond the flagship projects, the SUPINFO curriculum covers a broad base of technical modules, some of which directly fed the projects presented in this portfolio. A few modules by domain:

## Multi-vendor cloud

- **Microsoft Azure**: Azure Fundamentals, Azure AI Fundamentals.
- **Google Cloud**: GCP Cloud Engineer, Google Cloud Cybersecurity.
- **Cloud architecture**: Cloud Architecture Development (see [4ARCL](/en/projets/4arcl/)), GraphQL APIs (see [SchoolInc](/en/projets/4agql-proj/)).

## Networking, Linux & security

- **Networking**: CCNA v7 - Switching, Routing and Wireless Essentials (Cisco).
- **Systems**: Linux Professional Institute LPIC-2.
- **Application security**: Application Security, Personal Data Law (GDPR).

## Development & mobile

- **Web**: Advanced React Web Development, Node.js API Development, C#/ASP.NET, Microservices Development (see [TicketApp](/en/projets/4webd-ticket/)).
- **Mobile**: Android Developer, Hybrid application development with Ionic/React.
- **Containers & CI**: Docker (see [3DOKR](/en/projets/3dokr/)), Testing and Continuous Integration, Observability.

## Data & project management

- **Data**: NoSQL Databases, Big Data Fundamentals.
- **Project management**: Agile Method, Strategy & Specifications, Programme Manager, Managing Change.

## Why it matters

This foundation explains the ease of moving from one environment to another (VMware at Cloud Temple, AWS in a personal certification, Azure and GCP in the curriculum) rather than being locked into a single cloud ecosystem.
