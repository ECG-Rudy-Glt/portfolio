## Pourquoi l'AZ-104

Venant du DevOps (Kubernetes, Ansible, CI/CD Azure DevOps, monitoring), j'ai déjà les réflexes
d'exploitation - ce qui manque, ce sont les spécificités Azure elles-mêmes : Entra ID, le modèle
RBAC/Policy, le réseau Azure, le stockage. L'AZ-104 couvre exactement ce terrain-là. Plutôt que de
partir en révision au fil de l'eau, j'ai construit un plan sur 4,5 semaines, organisé par thème
d'examen plutôt que par ordre chronologique de découverte - histoire de ne pas laisser un domaine
entier pour la fin.

## Le contexte de l'examen

100 minutes, 40 à 60 questions, score de passage 700/1000, coût autour de 165$. La pondération par
domaine oriente directement le temps à investir sur chacun :

| Domaine | Poids |
|---|---|
| Identités & gouvernance (Entra ID, RBAC, Policy) | 20-25% |
| Compute (VM, VMSS, App Service, conteneurs) | 20-25% |
| Stockage (Storage Accounts, Blob, Files) | 15-20% |
| Réseau (VNet, NSG, Load Balancing, Bastion) | 15-20% |
| Monitoring (Azure Monitor, Log Analytics, backup) | 10-15% |

Nouveauté à noter sur la version actuelle de l'examen : plus de poids sur Entra ID/gouvernance, et
l'ajout d'ARM/Bicep, Container Apps, Bastion et Network Watcher au programme.

## Les ressources qui valent le temps investi

- **[Microsoft Learn - parcours AZ-104](https://learn.microsoft.com/training/courses/az-104t00)**
  + le Study Guide officiel - la base, gratuite et à jour par définition.
- **[John Savill's Technical Training](https://www.youtube.com/@NTFAQGuy)** - la référence vidéo
  pour cette certification, avec deux formats complémentaires : la
  *[AZ-104 Study Playlist](https://www.youtube.com/results?search_query=AZ-104+Study+Playlist+John+Savill)*
  complète (~20h, pour apprendre) et le *Study Cram v2* (~4h, pour réviser juste avant l'examen).
- **Whiteboard PDF récapitulatif** -
  [github.com/johnthebrit/CertificationMaterials](https://github.com/johnthebrit/CertificationMaterials)
  (dossier whiteboards) - un poster de synthèse par thème, utile pour une relecture active en fin
  de préparation.
- **Labs officiels Microsoft** -
  [github.com/MicrosoftLearning/AZ-104-MicrosoftAzureAdministrator](https://github.com/MicrosoftLearning/AZ-104-MicrosoftAzureAdministrator)
  (instructions rendues sur
  [microsoftlearning.github.io](https://microsoftlearning.github.io/AZ-104-MicrosoftAzureAdministrator/)).
- **Labs communautaires condensés** -
  [az-104-labs](https://github.com/Navid-Ishaq/az-104-labs) (21 labs ciblés) et
  [az-104-training](https://github.com/Georges034302/az-104-training) (CLI/ARM + Portail, avec
  nettoyage des ressources inclus).
- **Un compte Azure réel** - crédit gratuit de 200$ ou un lab sandbox, mais un compte réel dans
  tous les cas. Pas d'impasse possible sur la pratique : le format de l'examen inclut des
  questions "drag-and-drop"/scénario qui supposent d'avoir vraiment cliqué dans les blades Azure.
- **[Practice Assessment officiel](https://learn.microsoft.com/credentials/certifications/exams/az-104/practice/assessment)**,
  gratuit sur Microsoft Learn - à garder pour la toute fin, une fois les 5 domaines couverts, pour
  cibler la révision finale sur les points faibles réels plutôt que supposés.

## Le plan semaine par semaine

**Semaine 1 - Identités & gouvernance (20-25%)**
Modules Microsoft Learn : Entra ID (utilisateurs/groupes/licences/SSPR), RBAC, Azure Policy,
resource locks, tags, management groups/subscriptions, cost management. Vidéo : la partie
Identité + Gouvernance de la playlist Savill. Labs : création d'utilisateurs/groupes Entra ID,
assignation RBAC à différentes échelles, policy custom, resource locks (labs Navid-Ishaq 01-04).

**Semaine 2 - Stockage (15-20%)**
Storage accounts (types, redondance LRS/GRS/ZRS), Blob (tiers, lifecycle, object replication),
Azure Files, sécurité (SAS, clés, chiffrement), AzCopy, Storage Explorer. Labs : créer un storage
account, un partage SMB, une migration AzCopy, une restriction réseau sur le storage (Navid-Ishaq
05-09).

**Semaine 3 - Compute (20-25%)**
VM (création portail/CLI/ARM/Bicep), disques managés, availability sets/zones, VMSS, extensions
VM, App Service, notions de base Container Apps/AKS. Labs : déployer une VM via template ARM et
via CLI, availability set, VMSS, extensions (Navid-Ishaq 10-14 + le module compute de
Georges034302).

**Semaine 4 - Réseau (15-20%)**
VNet, peering, NSG, UDR, service/private endpoints, Bastion, load balancing (Load Balancer,
Application Gateway, Traffic Manager, Front Door), VPN et résolution DNS. Labs : peering VNet,
NSG + UDR, Bastion, déploiement d'un Load Balancer.

**Semaine 5 - Monitoring (10-15%) + révision finale**
Azure Monitor, Log Analytics, alertes, Network Watcher, backup/recovery. Puis relecture complète
du whiteboard Savill, visionnage du Study Cram v2 en entier avec prise de notes active, Practice
Assessment officiel pour repérer les points faibles restants, et un dernier tour sur les labs les
moins solides identifiés en cours de route.

## L'idée derrière ce découpage

Organiser par thème d'examen plutôt que suivre un cours dans l'ordre où il est structuré permet de
garder la pondération de l'examen en tête à chaque étape - le temps investi sur chaque domaine
reste proportionnel à son poids réel, et rien n'est repoussé faute de temps en fin de parcours.
